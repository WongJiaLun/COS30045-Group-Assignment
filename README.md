# Hospitalised Road Crash Injuries in Australia (2011 - 2021)
## COS30045 - Data Visualisation Project
### Project Overview

This Project aims to develop an interactive web based data visualisation to explore the hospitalised road crash<br>
injuries across Australia between 2011 and 2021.

Using data published by the Bureau of Infrastructure and Transport Research Economics (BITRE), the<br> 
project focuses on identifying meaningful patterns, trends and differences across selected categories.

The website will use D3.js to present the data through interactive charts, which allows users to explore and<br> 
compare hospitalisation statistics.

### Project Objectives 
The main objectives of this project are:
1. Analyse trends in hospitalised road crash injuries from 2011 to 2021.
2. Compare hospitalisation counts across selected categories, such as road user types, age groups and remoteness areas.
3. Identify meaningful patterns and differences in the dataset.

<hr>

### Dataset Information
Source: Bureau of Infrastructure and Transport Research Economics (BITRE)<br>
Period: 2011–2021<br>
Original file: hospitalisation_injury_publication_sep2023.xlsx<br>
Dataset URL: **https://www.bitre.gov.au/publications/ongoing/hospitalised-injury**<br>
The dataset contains hospitalisation counts and attributes like calendar year, age group,<br>
sex, road user types and remoteness area.
